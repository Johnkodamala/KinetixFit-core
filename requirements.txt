# KinetixFit — Android build requirements
#
# This is NOT a pip file: the app is React + Capacitor, so there are no Python dependencies.
# Every line is a comment, so `pip install -r requirements.txt` is a harmless no-op.
# It is the single checklist of everything needed to build the Android app on macOS.
#
# Install everything in one go:   ./scripts/setup-android.sh
# Keep this file and scripts/setup-android.sh in sync when a version changes.

# ── System toolchain (Homebrew) ────────────────────────────────────────────────
# node            >= 22            brew install node            (Capacitor 8 CLI minimum; verified on 26.0.0)
# npm             >= 10            ships with node              (verified on 11.12.1)
# openjdk@21      21               brew install openjdk@21      (AGP 8.13 needs JDK 17+; Capacitor 8 targets 21)
# android-commandlinetools         brew install --cask android-commandlinetools
# android-studio  (optional IDE)   brew install --cask android-studio   (used by `npx cap open android`)

# ── Android SDK packages (sdkmanager, into ~/Library/Android/sdk) ─────────────
# platform-tools                   adb, fastboot
# platforms;android-36             compileSdk / targetSdk 36 (android/variables.gradle)
# build-tools;36.0.0
# cmdline-tools;latest             sdkmanager, avdmanager
# emulator                         for running an AVD (needs a system image, created via Android Studio)
